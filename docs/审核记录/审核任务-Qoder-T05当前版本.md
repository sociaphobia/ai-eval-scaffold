## 审核范围与输出

请检查：

1. `baseline_id`／接纳事件引用从服务端、类型到 UI 的流转是否一致，失效或重新接纳时是否会错误绑定旧事件；
2. 项目、批次、报告异步切换是否存在过期响应覆盖新选择的状态问题，且保存中的交互是否安全；
3. 暂停依据、基线资格、题级结论和正式报告按钮之间的 UI 门禁，是否符合服务端契约；
4. `case_id` 共享编码向量是否被测试实际覆盖；
5. 页面、长文本、窄屏与键盘操作是否存在明确阻断问题；
6. 开发计划中的实现路径和当前代码是否一致，浏览器证据是否明示了自造样例、待验证边界和实际输出；
7. 生产方记录的每个关键行为是否能从实现／测试找到支撑。若外部运行期请求或真实业务样例未验收，应准确界定影响，不虚构已通过。

按“接受／修正性接受／驳回”逐条判定。每项发现给严重度、路径与行号、可复核原因和修复建议；无问题的审查面写明“接受”。最后说明结论只绑定本文件列出的 SHA。
