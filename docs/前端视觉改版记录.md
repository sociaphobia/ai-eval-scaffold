## 方案与实现

- **自拟主题**：浅灰绿画布、近白内容面、深绿导航和竹青强调色；正文用无衬线字体，主标题用中文衬线字体，数据数字采用等宽字体。基础与语义颜色、侧栏调色板、表面色及其透明度、字体、间距、圆角、阴影和焦点环定义于 `web/src/style.css`；`web/src/style-extra.css` 消费这些变量表达组件布局与颜色，不保留色值字面量。
- **主题接入**：Ant Design 6 的 `ConfigProvider` token 从上述 CSS 令牌读取，代码见 `web/src/main.tsx`。浏览器验证主按钮背景与 `--color-accent` 计算值一致。
- **状态颜色**：`pending`、`accepted`、`paused`、`invalidated`、`reported` 分别使用中性、绿色、琥珀、红色、竹青配色；状态文字、背景和边框颜色均来自 `style.css` 语义变量。它们继续显示原有状态文字，颜色不承担唯一含义。
- **窄屏导航**：视口不超过 1024px 时步骤条吸顶，顶栏改为普通文档流以免与导航重叠；不超过 640px 时步骤文案允许换行，不以裁切处理未来较长标签。
- **动效和打印**：遵循 `prefers-reduced-motion` 关闭页面入场动画，并保留既有的打印隐藏导航与卡片分页规则。
- **未改范围**：未改 `web/src/App.tsx` 的业务流程、后端接口、请求字段、数据库、评测规则或结果语义。

## 验收与证据边界

- `web/e2e/workflow.spec.ts` 在 FastAPI 与隔离 SQLite 数据库上完成原有导入、人工确认和报告流程；同时测量报告标签与五种批次状态标签对比度、主题主色一致性，并在 320、375、768、1440 像素视口检查宽度、导航吸顶、顶栏定位和四步文案。批次状态探针挂入页面实际渲染的 `.tabs` 容器内，并与真实选中批次按钮比较承载表面色；五类状态均断言其底色不同于该承载面。另临时改写基础 `--color-surface` 并用 Canvas 读像素，验证顶栏和空状态透明令牌随基础色变化。长文案探针额外验证换行与按钮内完整呈现。
- 同一浏览器 E2E 仿真 `prefers-reduced-motion: reduce`，读取入场动画计算值；切换至打印媒体后读取侧栏、顶栏显示、内容边距与题卡/指标的分页规则，再恢复屏幕媒体。
- 最近成功运行生成 `docs/T07前端视觉验收.json`、更新 `docs/T06浏览器请求记录.json`、`docs/T06浏览器报告.png` 和 `docs/T07前端视觉窄屏.png`。最新 JSON 记录 12 个对比度样本（7 个报告标签和 5 个批次状态探针），最低 `5.34:1`；五种前景色全部唯一，且五种状态底色均与选中承载面不同。“已出报告”标签对比度为 `5.95:1`，底色 `rgb(215, 232, 222)`，承载面 `rgb(232, 242, 237)`。响应记录为 47 请求、47 响应、非本机请求 0。
- 浏览器自动化使用 `tests/fixtures/演练规则误报基线.json` 与 `tests/fixtures/演练规则误报回归.json`。它们是项目自造样例，只能证明当前机制及界面路径可运行；项目方五类真实样例尚未提供，业务效果仍未验收。
- 本机取证来源：项目文件与真实浏览器运行；外部主题 API 依据采用 Ant Design 官方文档；`color-mix()` 语法与支持范围依据 [MDN 官方文档](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/color-mix)，页面标记 Baseline Widely Available、跨浏览器支持始于 2023 年 5 月，并说明可与 `transparent` 混合生成透明颜色。当前项目另以真实 Chromium 像素测试验证派生行为。Qoder 限免资格和模型按本机 AgentBridge 路由、CLI 返回和 [Qoder 官方活动说明](https://docs.qoder.cn/events/flashoffer)核对。

## 本轮复审处理记录

Qoder 首轮报告 `docs/审核记录/审核意见-Qoder-T07-前端视觉改版.md` 接受原冻结版本，指出六项低级改进。本节记录首轮处理与后续独立复审建议的关闭情况：

| 首轮建议 | 处理及理由 | 当前证据 |
| --- | --- | --- |
| 窄屏侧栏 `sticky` 没有有效偏移 | 加 `top: 0`；窄屏顶栏改为 `static`，避免两个吸顶层重叠。 | 320、375、768px 实测导航顶边为 0，顶栏定位为 `static`。 |
| Ant Design 主色与 CSS 变量双源 | `ConfigProvider` 颜色、圆角和字体从 CSS 变量读取。 | E2E 比较主题主色和主按钮计算背景，值均为 `rgb(47, 111, 95)`。 |
| 批次状态标签无语义色且未测对比度 | 为五类状态补中性、绿、琥珀、红、竹青令牌与样式，并将五类加入真实浏览器样式对比度测量。 | 首轮记录时的观察性口径；第三轮复审前已把断言收紧为恰好五种互异颜色，12 个总样本最低 `5.34:1`，高于项目 `4.5:1` 门槛。 |
