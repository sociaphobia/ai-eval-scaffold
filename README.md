# AI 应用评测脚手架

本项目在本机保存 AI 应用输入、评测依据、旧版基线、逐题人工结论和历史报告。评测数据只发往本机服务；规则结果用于提示，最终结论由评测人员确认。

## 关于本仓库

这是一个**文档与验收证据公开仓库**。

出于知识产权考虑，**实现源码不在此仓库中公开**。这里公开的是完整的设计与验收过程材料：需求、架构、开发计划、逐轮审核记录、浏览器验收报告与界面截图。

如果你想了解「这个系统怎么设计、怎么验证、验证到什么程度」，本仓库的内容即是完整答案。

## 技术栈

依据架构设计与开发计划文档，本项目采用：

| 层 | 选型 |
| --- | --- |
| 后端 | Python 3.13 + FastAPI（Uvicorn 启动） |
| 存储 | SQLite（本机单文件数据库） |
| 前端 | Vite + TypeScript |
| 测试 | pytest（后端）+ Playwright（浏览器端到端） |
